# TodayCommunity

커뮤니티 글의 링크와 목록 정보를 모아 보는 아카이브 프로젝트입니다. AI 실전 탭은 공개 구축·운영 사례를 선별해 한국어 제목과 3문장 안팎의 요약, 원제와 원문 링크를 제공합니다. 커뮤니티 본문과 이미지는 저장하지 않으며, AI 선별에 읽은 원문 전체도 공개 DB에 저장하지 않습니다.

서비스: [todaycommunity.pages.dev](https://todaycommunity.pages.dev)

DC Hot의 실제 수집 결과와 알림 판정은 분리합니다. `Collection alerts`는 출처 또는 파이프라인의 연속 실패 3회에 신호를 내고, 지속 시 실패 3회가 추가될 때 다시 알립니다. 정상 대기·예산 보류는 실패나 복구로 세지 않으며 실제 성공 뒤에는 다시 3회를 요구합니다. 원 수집 단계의 오류는 로그에 보존합니다. GitHub 플랫폼이 자체 판정한 원 실행 실패와 기본 알림은 별도이며, 원 실행이 이미 실패한 경우 observer의 추가 실패 신호는 억제합니다.

이 저장소에는 별도의 오픈소스 라이선스가 없습니다.
